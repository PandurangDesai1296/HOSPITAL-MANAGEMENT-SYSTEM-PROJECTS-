 🏥 Hospital Management System (HMS) - SAP ABAP S/4HANA

A complete SAP ABAP Hospital Management System developed using Custom DDIC Objects, Module Pool Programming, ALV Reports, SmartForms, Adobe Forms, BAPIs, and BAdIs.

This project demonstrates real-time SAP ABAP development concepts used in enterprise healthcare applications.

---

 📌 Project Overview

The Hospital Management System (HMS) manages the complete hospital workflow from patient registration to billing.

The application includes:

- Patient Registration
- Department Management
- Doctor Management
- Appointment Booking
- Patient Admission & Discharge
- Medical History
- Prescription Management
- Billing Management
- Reports
- SmartForms
- Adobe Forms
- BAPI Integration
- Custom BAdI Enhancements
